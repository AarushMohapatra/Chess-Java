# Chess... but programmed in Java
This program is my game project for Computer Science 2 in the high school. It contains a UI and an ok-ish chess bot that gets the job done.
## Instructions on how to run this
Since I have not learned yet how to build Java packages, you have to download the source code. Then, use your preferred method to run java. I highly prefer BlueJ, since this was programmed with BlueJ.
# Please note, you have to add your own background music in **.wav** format if you want background music.
